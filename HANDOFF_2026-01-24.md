## What This Project Is

Opportunity Finder is a web application that:
1. Reads from 6 data sources (Reddit, Indie Hackers, Product Hunt, Hacker News, Google Trends, SerpAPI)
2. Analyzes content using 10 detection criteria via AI (ZAI GLM 4.7)
3. Cross-references signals across sources
4. Displays opportunities in a dashboard

**Purpose:** Prove the opportunity-finding engine works. Personal use only - no auth, no payments, no multi-user.

## Context From Brainstorming Session

Key insights from earlier discussion:

1. **Competitors analyzed:** IdeaBrowser ($500-3000/yr), BigIdeasDB ($99 lifetime), GummySearch (shutting down Dec 2026)
2. **Our approach:** Combine multi-source (like IdeaBrowser) + pain point focus (like BigIdeasDB) + smart categorization (like GummySearch)
3. **Pluggable architecture:** Can add paid sources (BigIdeasDB, GummySearch) later if they provide better results
4. **10 criteria are universal:** Applied to ALL sources regardless of where data comes from
5. **No scoring yet:** MVP just finds opportunities and shows evidence - user judges quality manually
